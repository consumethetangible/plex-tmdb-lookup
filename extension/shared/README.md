# Generated folder: don't edit here

Everything in `shared/` is copied from the main project by `scripts/sync-core.mjs`:

- `shared/core/` comes from `js/core/`
- `shared/ui/` comes from `js/ui/`
- `shared/styles.css` comes from `css/styles.css`

Edit the originals, then run `npm run sync` from the project root. `npm test` fails if these copies fall out of date.
